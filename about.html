Hankilab 学习中心

v2.3.0

📖 应用介绍

Hankilab 学习中心是一款专注于英语跟读学习的 Progressive Web App（PWA）。 提供新概念英语（NCE）和 Think 系列课程的沉浸式学习体验，支持单句/全文模式、 智能重复播放、静音检测等特性，帮助您高效提升英语口语能力。

✨ 核心功能

🎯
单句/全文模式
🔁
智能重复播放
🔇
桌面端静音检测
⭐
句子收藏管理
📊
学习数据统计
🏆
成就徽章系统
📅
学习日历热力图
📱
PWA 离线支持

🛠️ 技术栈

HTML5 CSS3 JavaScript ES6+ Service Worker PWA localStorage Web Audio API
