隐私政策

1. 数据收集

本应用不收集任何形式的个人信息，包括但不限于：

  • 姓名、邮箱、电话号码
  • 设备信息、位置信息
  • 浏览记录、使用习惯

2. 数据存储

所有数据均存储在您的本地设备（localStorage）中：

  • 用户信息（昵称、年龄段）
  • 学习记录（时长、进度）
  • 收藏句子
  • 播放设置

数据永远不会上传到任何服务器。

3. 数据使用

存储的数据仅用于：

  • 提供个性化学习体验
  • 记录学习进度和统计
  • 保存用户偏好设置

4. 数据控制

您拥有完全的数据控制权：

  • 可随时在用户中心查看/export 数据
  • 可清除所有本地数据
  • 可清空浏览器缓存彻底删除

5. 第三方服务

本应用使用的第三方资源：

  • GitHub Pages：静态资源托管
  • Supabase：音频文件存储（仅读取）

这些服务不会收集您的个人数据。

6. 儿童隐私

本应用欢迎所有年龄段用户。如为儿童使用，建议家长陪同。

7. 政策更新

如有重大变更，将在应用内提示通知。
