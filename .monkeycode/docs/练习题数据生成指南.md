# 练习题数据自动化生成指南

## 📖 概述

本工具可以根据已有课程内容自动生成 5 种题型的练习数据，无需手动编写。

### 支持的题型

| 题型 | 自动化程度 | 说明 |
|------|------------|------|
| 听音辨意 | ✅ 完全自动 | 从同课/同书中选择干扰项 |
| 补全训练 | ✅ 完全自动 | 识别关键词并挖空 |
| 句子重组 | ✅ 完全自动 | 自动分词并打乱 |
| 跟读模仿 | ⚠️ 需自评分 | 使用通用评分标准 |
| 翻译练习 | ⚠️ 需人工审核 | 机器翻译准确度有限 |

---

## 🛠️ 使用方法

### 方式一：生成指定课程

```bash
# 格式
node tools/generate-practice-data.js unit <bookKey_unitKey> <audioKey>

# 示例：生成新概念第一册第 1 课
node tools/generate-practice-data.js unit NCE1_u001 L001

# 示例：生成 Think Level 0 第 1 课
node tools/generate-practice-data.js unit THINK_0_u001 T0_U01A
```

### 方式二：生成所有课程

```bash
node tools/generate-practice-data.js all
```

## 📁 LRC 文件格式支持

### 标准 LRC 格式

```lrc
[00:00.50]Excuse me!
[00:02.00]Yes?
[00:03.50]Is this your handbag?
[00:05.50]Pardon?
[00:07.00]Is this your handbag?
[00:09.00]Yes, it is.
[00:10.50]Thank you very much.
```

### 带中文翻译的 LRC 格式

```lrc
[00:00.50]Excuse me!
[00:00.50]<cn>打扰一下！
[00:02.00]Yes?
[00:02.00]<cn>什么事？
[00:03.50]Is this your handbag?
[00:03.50]<cn>这是你的手提包吗？
```

### 使用 LRC 文件生成数据

1. **准备 LRC 文件**

   将 LRC 文件保存到 `audio/{BOOK}/` 目录，命名为 `L{编号}.lrc`

2. **解析 LRC 文件（可选脚本）**

   ```bash
   node tools/parse-lrc.js ./audio/NCE1/L001.lrc
   ```

3. **更新 data.json**

   将解析结果添加到 `data.json` 的 `units` 部分

4. **生成练习题**

   ```bash
   node tools/generate-practice-data.js unit NCE1_u001 L001
   ```

## 📊 生成规则

### 1. 听音辨意（Listening）

**策略**：
- 优先从**同一课**的其他句子中选择干扰项
- 其次从**同本书**的其他课中选择
- 最后使用**通用词库**（问候语、肯定/否定句等）

**示例**：
```json
{
  "listening": {
    "options": [
      {"text": "这是你的手提包吗？", "correct": true},
      {"text": "打扰一下！", "correct": false},
      {"text": "请坐。", "correct": false}
    ]
  }
}
```

### 2. 补全训练（Fill Blank）

**策略**：
- 排除冠词（a/an/the）、介词（in/on/at/to）等功能词
- 优先挖空名词、动词、形容词、代词
- 干扰项选择同词性的常见词

**示例**：
```json
{
  "fillBlank": {
    "template": "Is ______ your handbag?",
    "options": ["this", "that", "it"],
    "answer": "this",
    "hint": "指示代词"
  }
}
```

### 3. 句子重组（Ordering）

**策略**：
- 按空格分词
- 保留标点符号依附于单词
- 完全随机打乱顺序

**示例**：
```json
{
  "ordering": {
    "words": ["handbag?", "your", "this", "Is"],
    "answer": ["Is", "this", "your", "handbag?"]
  }
}
```

## 🔧 自定义配置

编辑 `tools/generate-practice-data.js` 中的 `CONFIG` 对象：

```javascript
const CONFIG = {
  // 干扰项数量
  distractors: {
    count: 2,  // 改为 3 则每个题目 3 个干扰项
  },
  
  // 补全训练
  fillBlank: {
    variantsPerSentence: 1,  // 改为 2 则每个句子生成 2 个变体
  },
  
  // 音频 URL 模板
  audioURL: {
    NCE1: 'https://your-cdn.com/nce1/{audio}.mp3',
  },
};
```

## 📝 工作流程

### 新课件上传流程

```
1. 准备音频文件
   └─ audio/NCE1/L010.mp3

2. 准备 LRC 歌词文件（可选）
   └─ audio/NCE1/L010.lrc

3. 解析 LRC 文件
   └─ node tools/parse-lrc.js ./audio/NCE1/L010.lrc

4. 更新 data.json
   - 添加课程信息到 units
   - 包含 lines 数组（时间戳、英文、中文）

5. 生成练习题
   └─ node tools/generate-practice-data.js unit NCE1_u010 L010

6. 验证生成结果
   - 检查 practice_questions 数据
   - 手动调整不合理的干扰项

7. 完成！✅
```

## ⚠️ 注意事项

### 干扰项质量

- 工具生成的干扰项可能不够准确
- **建议**：生成后人工审核，替换不合理的干扰项
- **特别是**：听音辨意的干扰项应与正确答案语义相近

### 句子长度

- 少于 3 个词的句子无法生成补全训练和句子重组
- 工具会自动跳过或生成简化版本

### 特殊标点

- 标点符号会保留在单词上（如 "handbag?"）
- 分词时使用空格分割，可能不适合所有语言
