# 练习数据自动化生成 - 完整方案

## ✅ 已实现功能

### 1. 一键导入工具 (`tools/import-course.js`)

**一条命令完成全流程**：
```bash
node tools/import-course.js ./audio/NCE1/L001.lrc \
  --book NCE1 \
  --unit u001 \
  --audio L001 \
  --title "Lesson 1-2"
```

**输出**：
- ✅ 解析 LRC 文件（提取时间戳、英文、中文）
- ✅ 更新 data.json（添加课程数据）
- ✅ 生成练习题（5 种题型，共 8 道）

---

### 2. 独立工具（按需使用）

#### LRC 解析器 (`tools/parse-lrc.js`)
```bash
# 仅解析，不保存
node tools/parse-lrc.js ./audio/NCE1/L001.lrc

# 解析并保存到 data.json
node tools/parse-lrc.js ./audio/NCE1/L001.lrc \
  --book NCE1 --unit u001 --audio L001 --output
```

#### 练习题生成器 (`tools/generate-practice-data.js`)
```bash
# 生成指定课程
node tools/generate-practice-data.js unit NCE1_u001 L001

# 生成所有课程
node tools/generate-practice-data.js all
```

## 📊 生成的题型数据

### 1. 听音辨意（Listening）
```json
{
  "listening": {
    "options": [
      {"text": "这是你的手提包吗？", "correct": true},
      {"text": "打扰一下！", "correct": false},
      {"text": "请坐。", "correct": false}
    ]
  }
}
```
**策略**：从同课/同书中抽取干扰项

---

### 2. 补全训练（Fill Blank）
```json
{
  "fillBlank": {
    "template": "Is ______ your handbag?",
    "options": ["this", "that", "it"],
    "answer": "this",
    "hint": "指示代词"
  }
}
```
**策略**：排除功能词，优先挖空实词

---

### 3. 句子重组（Ordering）
```json
{
  "ordering": {
    "words": ["handbag?", "your", "this", "Is"],
    "answer": ["Is", "this", "your", "handbag?"]
  }
}
```
**策略**：按空格分词，随机打乱

---

### 4. 跟读模仿（Speaking）
使用通用评分标准，用户自评：
- ⭐⭐⭐ 发音标准
- ⭐⭐ 基本准确
- ⭐ 需要改进

---

### 5. 翻译练习（Translation）
```json
{
  "reference": "这是你的手提包吗？"
}
```
**策略**：直接使用 LRC 中的中文翻译

## ⚠️ 注意事项

### 1. 干扰项质量
- ✅ 工具会自动选择语义相关的干扰项
- ⚠️ 建议人工审核第一遍
- ❌ 避免明显的错误干扰项

### 2. 句子长度
- 少于 3 个词的句子无法生成"补全训练"和"句子重组"
- 工具会自动处理（使用简化版本或跳过）

### 3. 中文翻译
- 如果 LRC 中没有中文，工具会用英文填充
- 建议手动补充准确的中文翻译

### 4. 特殊格式
- LRC 中的元数据标签（ti:、ar:、al:）会自动忽略
- 支持标准时间戳格式：`[mm:ss.xx]`
